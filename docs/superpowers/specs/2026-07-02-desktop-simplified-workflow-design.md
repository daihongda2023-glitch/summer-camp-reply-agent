# 桌面版三步工作流布局设计

## 背景

当前桌面主界面同时展示视觉观察、手动生成、消息流、决策面板、回复草稿和多个低频入口，用户进入后不容易判断下一步该做什么。新版布局以“观察消息、处理消息、发送回复”的三步工作流为主线，降低分区数量和按钮噪音。

## 设计目标

- 主屏只突出一个清晰流程：观察/识别、选择待处理消息、编辑并发送回复。
- 低频能力保留入口，但不占据主操作区域。
- 决策信息作为选中消息的辅助详情展示，不和消息列表、回复区争夺注意力。
- 不改变现有 IPC、后端接口、视觉观察和回复动作的行为。

## 信息架构

主窗口分为三块：

1. 左侧状态栏：展示产品名、微信观察状态、当前窗口或群聊，并提供“配置”和“工作轨迹”入口。
2. 中间主工作区：顶部为三步状态和观察操作，中部为待处理消息列表，底部为回复草稿和发送动作。
3. 右侧详情栏：展示选中消息的关键上下文、建议动作、置信度和来源。

## 交互规则

- “启动观察”“识别当前窗口”“刷新”放在主工作区顶部，作为第一步入口。
- 空消息列表直接提示用户启动观察或手动输入问题生成草稿。
- 手动生成改为主工作区内的紧凑输入条，不再作为左侧独立模块。
- 回复动作固定在回复草稿下方，顺序为“填入微信”“我已发送”“保存候选”。
- 右侧详情只展示辅助决策信息，不放主要操作按钮。

## 验证标准

- 静态测试通过。
- TypeScript 类型检查通过。
- 窄屏下布局能降级为单列，按钮不溢出。
- 主窗口首屏能明显看出三步工作流。
