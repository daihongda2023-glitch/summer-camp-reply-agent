# 夏令营自动回复 Agent

## Problem Statement

如何帮助参加沐曦股份首届开源英才夏令营的学生，在报名、线上学习、实践作业、面试选拔、入营准备和线下集训全过程中，快速获得可靠答案和下一步行动，同时减少组委会在企业微信群里的重复答疑压力？

## Recommended Direction

建议将第一版定位为“阶段式 FAQ + 现场服务 + 人工升级”的企业微信群 agent，而不是全能导师。它主要面向学生，围绕活动流程、规则说明、资料入口、日程安排、食宿交通、现场服务等高频问题自动回复；对资料未覆盖、涉及个人状态、技术作业指导或需要组委会判断的问题，明确升级给人工负责人。

这个方向的核心价值是稳定和可信。夏令营场景里，学生最常见的问题往往不是复杂技术问题，而是“我能不能报名”“什么时候面试”“作业怎么提交”“交通是否报销”“线下住哪里”“今天几点集合”。这些问题高频、标准、可沉淀，适合自动化。技术问题可以支持概念解释和资料导航，但不替代导师答疑，也不帮助学生完成作业。

产品应按活动阶段组织知识：报名申请期、线上学习期、实践作业期、面试选拔期、入营准备期、线下集训期、结营后延展。每个阶段都有自己的常见问题、关键提醒、人工升级规则和资料来源。后续资料补充时，只要归入对应阶段，agent 就能持续变得更可靠。

## Key Assumptions to Validate

- [ ] 学生 70% 以上的问题可以从官方招募文章、群公告、课程日程、作业说明、面试通知和线下手册中回答。验证方式：收集企业微信群 1-2 周真实问题并分类统计。
- [ ] 学生会接受 agent 在群内自动回复，而不会觉得打扰。验证方式：先限制触发频率，只在被 @ 或命中明确问题时回复，观察群内反馈。
- [ ] 组委会愿意持续补充资料并处理未命中问题。验证方式：建立“未覆盖问题日报”，看运营同学是否能每 1-2 天补一次知识库。
- [ ] 线下集训体验的主要痛点集中在日程、场地、签到、住宿、餐饮、分组、设备、联系人等事务性信息。验证方式：在入营前收集学生最担心的问题，并在集训第一天复盘实际提问。

## MVP Scope

第一版只做企业微信群内的学生答疑助手，能力范围如下：

- 基于官方资料回答报名对象、活动时间、活动地点、费用安排、食宿交通、选拔流程、报名入口、官方群、主办/支持/合作单位等问题。
- 根据当前活动阶段，优先回答该阶段最相关的信息。
- 对资料未明确的问题不编答案，回复“当前资料未明确”，并给出人工升级或等待通知的下一步。
- 记录未命中的问题，形成后续资料补充清单。
- 支持少量主动提醒，例如报名截止、作业提交、面试安排、入营准备、当日集合提醒；默认低频，避免刷屏。

## Not Doing (and Why)

- 不做报名资格自动判定：学生背景复杂，自动判断容易误导，应引导查看报名对象并必要时咨询组委会。
- 不做录取结果和个人状态查询：涉及隐私、名单权限和通知节奏，不应在群内自动暴露。
- 不做技术作业代答：夏令营目标是训练工程实践能力，agent 只能做资料导航、概念解释和规则提醒。
- 不做完全无人值守：活动场景变化快，必须保留人工兜底。
- 不做复杂学生画像和长期记忆：第一版先验证高频问答价值，避免增加隐私和运维负担。

## Open Questions

- 企业微信机器人是通过群机器人 webhook、企业微信应用，还是第三方平台接入？
- 群内自动回复是否只在被 @ 时触发，还是允许关键词命中自动回复？
- 组委会是否能提供课程日程、作业规则、面试规则、线下手册、联系人和紧急预案？
- 未命中问题由谁每天审核并补充知识库？
- 是否需要支持多群：报名咨询群、入营学生群、导师/助教工作群？
